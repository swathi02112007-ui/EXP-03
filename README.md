# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:

To develop a Railway Management System using UML diagrams to represent the structure, functionality, and interactions of the railway reservation system.

# SRS PROCEDURE:

1. Study the requirements of the Railway Management System.
2. Identify the actors and their roles in the system.
3. Prepare the Software Requirement Specification (SRS).
4. Identify the functional and non-functional requirements.
5. Draw the Use Case Diagram to represent user interactions.
6. Draw the Class Diagram to represent classes and their relationships.
7. Draw the Sequence Diagram to represent the flow of messages between objects.
8. Draw the Activity Diagram to represent the workflow of railway ticket booking.
9. Verify and save all the UML diagrams using StarUML.
